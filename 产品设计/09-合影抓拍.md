# 合影抓拍 · 产品设计

## 一句话
六个人合影，没一个老实的：等全员都看镜头的那一瞬间，按下快门。

## 灵感与定位
- 玩法借鉴 keifurukawafunnych.com 的合影时机类小游戏（朋友合影时总有人眨眼、走神、躲开，玩家要在全员状态都好的瞬间抓拍），原创实现：状态机、计分、文案、视觉全部自研。
- 定位：观察 + 时机判断的轻游戏。规则一句话说清，一局 5 张胶片、每张全靠等时机；「就差一个人」的懊恼和全员就绪的完美瞬间天然有传播性，定格照片的逐人标注（谁眨眼、谁看别处、谁蹲下）就是现成的笑点素材。

## 核心玩法
1. 6 位朋友站成一排合影（不同长相 emoji 区分），每人独立随机切换状态，状态持续约 0.6–2.2 秒：
   - 就绪（正脸微笑，约 55%）：可以拍；
   - 眨眼（😑）：不行；
   - 看别处（🙄，头像轻微旋转）：不行；
   - 蹲下（整个人下沉只露头顶，约等于不在画面）：不行。
2. 点大快门按钮拍照，瞬间定格计分：每位就绪者 +15 分，6 人全就绪额外 +10，满分 100。闪光 + 快门框收缩动画，照片以拍立得样式滑出，逐个标注谁眨眼、谁看别处、谁蹲下了。
3. 每局 5 张胶片（5 次拍照机会），拍完一张可看标注再继续拍下一张，人物状态持续变化；5 张拍完结算，取最佳一张为成绩，画廊展示全部 5 张（拍立得缩略 + 分数）。
4. 评级按最佳分数：100「完美合影」；≥85「抓拍大师」；≥70「还不错」；≥50「有点遗憾」；<50「全是废片」。
5. 本地保存最佳纪录（最高分）和游玩局数，首页展示；结算页可生成成绩卡图片（保存相册 / 发小工具卡 / 发笔记）。

## 页面
- 首页：标题、最佳纪录、开始拍照、玩法一句话说明（等全员就绪再按快门）。
- 拍摄页：取景框场景（渐变天空 + 地面、相机 UI 边角、REC 指示），6 位朋友一排站立，状态切换只更新变化的人；下方胶片余量（5 个胶片点）和大快门按钮。
- 单张结果：拍立得照片滑出（定格瞬间各人表情 + 蹲下者下沉），得分数字跳动，逐人问题标注标签；按钮「拍下一张」或（胶片用完时）「看结算」。
- 结算页：最佳分数（数字跳动揭晓）、评级、最佳照片拍立得、5 张画廊缩略与分数、成绩卡预览与分享、再来一局。

## 平台能力
- Storage 存最佳纪录；vibrateShort 快门反馈；Canvas 生成成绩卡；saveImageToPhotosAlbum / share / postNote 分享。
- 纯前端单机，无网络、无账号；授权仅需 photos（保存成绩卡）。

## 传播设计
- 结算文案带钩子：「5 张胶片，最好的那张还是有个人蹲下了」；<50 分的「全是废片」自带吐槽属性。
- 成绩卡含最佳照片示意图（按定格瞬间绘制 6 人状态排布）、最佳分数、评级、5 张画廊分数列表，一眼看懂玩法和遗憾点。
- 后续可加：9 人大合影难度、连拍模式、好友挑战码——v1.1 再议，先验证核心手感。
