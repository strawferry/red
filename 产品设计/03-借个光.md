# 借个光产品设计

饭局、夜景和室内聚会拍照时，打开小工具就能用屏幕补光。首次用柔白，之后恢复已保存的光色。想换风格时，可点预设、自定义光色，或从首屏开启随机霓虹。另一部手机可以直接拍。想同机拍照时，再点进「补光自拍」。前置相机、保存和发笔记走完双端真机验证后再作为上线卖点。

| 用途 | 文案 | 理由 |

| 创服简介 | 手机屏幕柔光补光 | 即使首发先开补光板也准确。 |
| 直白型备选 | 夜拍补光板 | 从搜索结果里容易看懂，适合作为笔记关键词。 |
| 拍摄型备选 | 补光一拍 | 适用于补光自拍通过真机验证并上线之后。 |

## 首屏与拍摄流程

| 画面 | 用户操作 | 设计细节 |
| --- | --- | --- |
| **补光板** | 打开即亮。底部直接点「柔白」「暖光」「冷白」「随机霓虹」，也能进「更多光色」或「补光自拍」。 | 首次使用柔白，之后优先恢复上次光色。调光条始终对应光板明暗。常亮时轻点光面隐藏控件，再点恢复。霓虹模式下，点光面会暂停或继续。 |
| **补光自拍** | 第一次点入口时按系统提示授权相机。快门右侧的「灯光」可在取景时调明暗、选预设、自定义或换霓虹。收起面板后按快门，可选 3 秒倒计时。 | 竖屏中央放小预览，四周保持常亮。打开灯光面板时取景留在面板上方，相机继续运行。进入自拍时继承当前光色，滚动中的氛围灯定格在当前渐变，自拍里可换一组。预览与成片的裁切和方向对齐。 |
| **成片** | 主按钮「存相册」，次按钮「发图文」，旁边可重拍。 | 迅速退出实时取景，成片放在深灰背景上便于判断亮度。「发图文」带图片进入小红书笔记编辑页，由用户编辑或确认发布。 |

## 光色、氛围与反馈

「更多光色」合在一个底部面板，底色在面板后实时预览。选完收起面板，屏幕重新把面积留给光板。

| 功能 | 首版设计 |
| --- | --- |
| 场景预设 | 首屏常用光为柔白 `#FFF9F2`、暖光 `#FFD9B1`、冷白 `#DDEAFF`。更多面板加蜜桃、粉紫和冰蓝三种氛围色。每个预设有名称、色块和一句场景提示，例如「柔白 · 先给暗处合照补一点光」「粉紫 · 试试给夜景人像侧脸染色」。 |
| 自由调色 | 用颜色和饱和度面板选颜色，拖动即时预览，松手确定。光板明暗独立控制，调完仍可一键切回柔白。 |
| 随机一色 | 点一次，从预设和精选色板中换一个与当前不同的常亮颜色。选中的颜色会保持，方便两部手机拍同一组照片。 |
| 随机霓虹 | 从首屏开启。渐变色带在移动的同时，约每 3.2 秒平滑换到另一组随机配色。再次点「随机霓虹」可以立即换一组。**点一下光面停在当前画面，再点一下继续。** 选固定色直接切到常亮，退后台暂停。减少动效模式显示静态渐变，点光面换一组配色。 |

切进霓虹时短暂提示「点一下光面暂停，再点继续」。停住时轻显「已暂停」。点光面的手势只覆盖灯光区域，调色面板、滑条和相机控件各自响应。

主动切换预设、确认自定义颜色、随机换色、启动、暂停或继续霓虹时给一次轻振。设备和客户端支持时用平台的短振动，默认开，设置里可关。音效独立控制，**默认关闭**。开启后才在主动切换时播放轻短提示音，发声方案走双端真机检查。持续调色和霓虹滚动时，反馈只由用户的确认或换模式动作触发。 [小红书振动反馈](https://miniapp-sandbox.xiaohongshu.com/minitool/doc#s3-13)

## 视觉与光板

两部手机的用法是将开着灯板的手机放在拍摄者一侧，对准人物，拍摄者用另一部手机拍。取景组件避让宿主顶部按钮和底部安全区。控制区为半透明深色条，霓虹时尽量把可点的区域留给光面。图标用一块柔白圆角屏围住一个深灰色小取景窗。亮度滑条说明写「光板明暗」，实际照明还取决于系统屏幕亮度、距离和环境光，用户可从系统设置调节屏幕亮度。 [小红书窗口信息](https://miniapp-sandbox.xiaohongshu.com/minitool/doc#s3-11)

## 功能与平台边界

- **光板可独立发布。** 预设色、自由调色、单次随机和霓虹渐变都在本地页面运行。容器 Storage 可用且写入成功时，可恢复上次固定色或霓虹状态，也会记住振动与音效偏好。屏幕亮度、息屏和宿主顶部 UI 由系统或容器管理。 [小红书本地缓存](https://miniapp-sandbox.xiaohongshu.com/minitool/doc#s3-7)
- **相机版按真机可用性开放。** 小红书开发者文档允许在用户授权下用 `getUserMedia` 请求摄像头。实现时请求可验证的前置视频流，等真实帧到达后开放快门，用 Canvas 按预览裁切导出本地静态照片。遇到权限拒绝、相机占用、黑屏、前置不可用或相机能力缺失时，提示原因并保留亮灯入口。离开自拍页和退后台时停止相机流，返回后由用户重新打开。 [小红书媒体能力](https://miniapp-sandbox.xiaohongshu.com/minitool/doc#s2-3) · [W3C 媒体采集规范](https://www.w3.org/TR/mediacapture-streams/)
- **成片进入相册或笔记。** 相册使用 `saveImageToPhotosAlbum`，文档标注客户端 9.42+，且可能需相册授权。较大的图可先通过 `writeTempFile` 转为容器内临时路径。发图文使用 `postNote` 携带图片和可改标题正文，用户在发布页决定是否发送。失败时保留当前成片，可重新保存或再次打开发布页。 [保存相册](https://miniapp-sandbox.xiaohongshu.com/minitool/doc#s3-4) · [临时文件](https://miniapp-sandbox.xiaohongshu.com/minitool/doc#s3-5) · [发笔记](https://miniapp-sandbox.xiaohongshu.com/minitool/doc#s3-3)
- 双颜色分区、后置取景、连拍、录像和滤镜进入后续评估。首版的辨识点是常亮光面、小预览和拍完后的「发图文」入口。

## 首版与验证

1. 打开页面立即能用补光板。检查常用预设、自由调色、明暗独立、随机换色，以及从首屏开启霓虹后是否持续换色。另查暂停时颜色和位置一起定格，重新打开后能恢复写入成功的光色。
2. 用安卓和 iOS 的小红书真机验证授权、前置选取、取景、快门、倒计时取消、重拍和退出后释放相机。取景时打开「灯光」，核对画面持续更新，调色和调明暗立即反映到光板，收起后可继续拍摄。权限拒绝和画面中断时可继续使用灯板。
3. 同一场景固定人物、距离和构图，拍一组灯板关闭和打开的对照。单独验证双机补光与同机自拍。观察脸部细节、肤色、过曝和低亮度表现，用实拍素材做推广。
4. 核对预览与成片的裁切和镜像。相册实际收到文件才显示「已保存」，发图文需真机看到笔记编辑页带入正确图片。若同机效果或稳定性未达标，首发继续用灯板文案，相机路径保留为后续版本。
5. 双端检查主动换色的轻振、音效初始关闭和开启后能再关闭。反馈次数与用户确认动作一致。进入霓虹后，点光面停在当前画面，再点可从该画面继续。分别验证点滑条或相机控件、切换自拍时定格、退后台和减少动效设置。

## 分享与推广

**主传播素材是同一环境的补光前后对照。** 用真实照片做封面或首段，第二段展示拿另一部手机当灯的动作。首发笔记挂载工具，读者可直接试。自拍通过真机验收后，增加「拍完去发图文」演示。用户保存的是自己拍的图，是否挂载工具由用户在笔记编辑时决定。 [小红书挂载说明](https://fe-video-qc.xhscdn.com/fe-platform-file/104101b8322bpulog7u06f48k3g2740000000016rhrpc6)

**首发标题**　饭局太暗？拿另一台手机借个光

**正文**

> 晚上吃饭拍合照，脸总比背景暗。让朋友打开「借个光」，把发光的那面朝向人，拿另一部手机拍。同一个位置先用柔白，再试试暖光，看你更喜欢哪张。
>
> 想拍点彩色的，去「更多光色」点随机一色，也可以直接点底部的「随机霓虹」。碰到喜欢的一帧就点一下屏幕，把颜色定住，再拍一张。下次聚餐可以提前把这条发给拍照搭子。

**自拍版追加文案**　「只有一部手机，点『补光自拍』。中间看取景，四周接着亮。拍完可以存相册，也能把这张带进小红书发笔记。」这段随自拍版上线使用。

**封面大字**　饭局太暗　借个光

**15 秒视频**　0–3 秒展示原环境的第一张。3–7 秒给朋友拿着手机开灯的侧拍。7–11 秒并排展示同距离实拍前后。11–15 秒拍工具首屏，从柔白切到暖光，最后露出笔记挂件。

**后续选题**　聚餐合照、夜景人像、房间窗边暗处，分别保持场景一致拍两张。氛围版可拍「随机到粉紫，再把滚动霓虹停在喜欢的一帧」。自拍版本再发一个「只有一台手机怎么打光」的完整演示。
